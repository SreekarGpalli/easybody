# EasyBody

A phone web app for the EasyBody 24-week plan.

- **Today:** the session for the day, worked out from your start date. Tap a numbered circle after each set; the rest timer starts on its own. Weights carry over from last time.
- **How:** the play button on any exercise opens an animated form guide showing breathing, tempo and the muscles working.
- **Routines:** short, research-backed habits that count toward the Daily ring: morning daylight, desk breaks every 30 min, after-meal walks with a caffeine cutoff, and an evening wind-down. Each shows why it works. Settings sets the times and can download calendar reminders.
- **Progress:** training-day streak (rest days never break it), this week's sessions, program week and lift trends.

Install it from your phone's browser:

- iPhone (Safari): Share → Add to Home Screen
- Android (Chrome): menu → Install app

History is stored on the device only (Settings has backup and restore). Works offline after the first load.
